Catalog builder

A browser cannot list a folder, so paste the paths you added and this probes them over HTTP — reading each folder's Label.txt, Warning.txt, meta.txt or proxy.txt exactly like the old Node scripts did. Then copy the output over src/catalog/generated-catalog.js.

How NULL reads a folder

games/name/name.html — the launch file. index.html also works.

Label.txt — one or more chips per line; Label: Action Puzzle and a bare Action Puzzle both work, and 2 Player stays one label.

Warning.txt — Title: … and a Description: that runs on over following lines; shown before the game launches.

meta.txt — Name:, Description:, Added: YYYY-MM-DD (NEW badge for 14 days) and a line containing #hot for a HOT badge.

Thumbnail — any png jpg jpeg webp gif svg, named after the folder (snake.svg) or cover./thumb.; missing thumbs fall back to NULL's placeholder art.

proxies/name/proxy.txt — Link: (required), Description:, Status: (All Good | Issue | Blocked).

Folders starting with . or _ are ignored.
