## 👀 what is null?
**null** (yes, strictly lowercase) is a premium, next-generation unblocked games site inspired by platforms like Cherri. It is built primarily for getting around restrictions on school chromebooks, or for anyone who just wants to play games web-side without the fluff. 

> *Note: null relies on custom client-side rendering and **cannot** be deployed on GitHub Pages.*

## 🚀 deployment methods
since standard static hosting like GitHub Pages won't work due to routing and JavaScript requirements, use these deployment alternatives:

### ⚡ method 1: cloudflare pages (recommended)
1. fork this repository.
2. go to your **Cloudflare Dashboard** -> **Workers & Pages** -> **Create application** -> **Pages**.
3. connect your GitHub account and select the `null` repository.
4. leave build settings default and hit **Save and Deploy**.

### 🟢 method 2: vercel / netlify
1. import this repository directly into your **Vercel** or **Netlify** dashboard.
2. ensure the build command is left blank (or uses your default bundler script if applicable).
3. deploy!

### 💻 method 3: local hosting
run a local development server using Node.js:
```bash
# clone the repository
git clone https://github.com/mr-blobbb/null.git
cd null

# install a simple static server if you don't have one
npm install -g local-space-server # or your preferred server tool

# fire it up
npx serve .
```
